# Link & Traffic Tracker API

REST API-сервис для создания коротких ссылок и сбора статистики по кликам (каналы, кампании, страны, устройства).

## Идея

- Создавать короткие ссылки вида `/l/:code`.
- Считать клики по ним (время, IP, user-agent и т.д.).
- Смотреть статистику по конкретной ссылке или кампании.
